Settings — Trading Objectives tab (Target Yield) — Issue #207

Read-only HTML/Tailwind mock of the V1.0.3 stopgap that fixes the dead-ending "Set target yield →" Recovery Plan CTA. A new third Settings tab — Trading Objectives — holds a single field, Target Yield. Each state below is rendered as its own stacked section. Click-throughs are visual cues only — nothing is interactive. This is the minimal stopgap, NOT the full V1.1 OKR Scorecard.

States covered: 1. Unset / empty (first run) · 2. Populated (value set) · 3. Inline validation error · 4. Saving (form disabled) · 5. Save success · 6. Save failure banner · 7. Loading skeleton · 8. Load error · 9. Recovery CTA — before / after.
